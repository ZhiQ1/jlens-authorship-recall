Stage 13B 读出工具C 哪一层 计划：中间层到底表示什么

计划写于 2026-10-28；状态随实验更新。

出发点

lens 读不出，只能说明“这种解码方式读不出”，不能说明信息不存在。logit lens 和三种 Jacobian lens 做的是同一件事：把某一层的表示直接翻译成“下一个词”，再看正确名字排第几。可是早期和中间层可能根本不在表示答案，而是在表示别的东西，比如“这是一个找作者的任务”“这篇论文是哪一篇”“接下来要输出人名格式”。这些信息可以真实存在，只是不在“名字”这个方向上，用名次去量自然量不出来。

现有数据支持这种看法：

  • Stage 11 替换显示，论文信息在 L24–L50 就从标题被读走，搬到标题后面那几个 token 上（L48 恢复 83%，L52 起 100%）；从 L52 起阻断对标题的注意力已没有影响。
  • 同一时期，在名字位置用 lens 几乎读不出作者（标题特异信号 L24–L48 约为 0）。
  • 换成在标题最后一个 token 上训练的线性 probe，从 L16–L24 起就能读出少量这篇论文特有的作者信息（+0.04 到 +0.08），而且对照检验证明它是这篇论文特有的。

信息在动，只是还没变成“名字”的形式。这一阶段要回答：中间层表示的是任务、论文身份，还是以另一种形式存在的作者信息？这是 Line B（读出工具）和 Line C（哪一层）之间的新方向。

三种假设及其预测

假设M1：lens 在中间层排第一的词M2：probe 读非名字的属性M3：换任务对照
H1 任务 / 格式：中间层在表示“要输出作者名单”多为 “author”、标点、名字常见开头，与标题无关论文属性读不出或很弱同一标题在不同问题下，中间层表示早早分开
H2 论文身份：中间层在表示“是哪一篇论文”与标题有关的词（照抄标题），换假标题就变领域、年份（从标题推出）、引用数、是否认得出都读得出，且早于名字不同问题下同一篇论文的表示在中间层相近，后期才按任务分开
H3 作者信息已在，只是不在词表方向不一定作者首 token 用 probe 读得出，lens 读不出按作者训练的 probe 能跨任务迁移；作者专用 lens（M4）在中间层读得出名字

三者不互斥。实验的目标是看每一层主要是哪一种，以及“论文身份”出现的层是否早于“名字”出现的层。

实验

编号做什么数据与计算状态
M1 lens 在读什么Stage 10 每个名字 token、每种读出、每层都存了排第一的词。把它分类：正确的词 / 像人名开头的词（队列中任一作者名字的首 token）/ 标点与格式 / 任务词（author、paper、et、al 等）/ 从本题标题照抄的词 / 其他。另算：把真标题换成假标题后，排第一的词变了的比例（即使读错，读出是否随标题变）。已有数据，CPU。真标题、假标题 false_0、删去标题三种条件；全部名字 token 与每个名字的首 token 分开统计。CPU 作业 11438885 已提交
M2 probe 读非名字的东西在 Stage 11 存下的残差上训练线性 probe（标题最后一个 token：L16–L60；“:” 位置：L16–L63；全部 9,108 篇）。目标：领域（8 类准确率）；发表年份（R²，在标题最后一个 token 上模型还没读到年份，读得出就说明它从标题认出了论文）；引用数（R²，“名气”）；是否认得出（target vs control，引用档内 AUROC）。每个目标都做打乱标签的对照；假标题 false_0 的运行用标题所属论文的标签，检验 probe 读的是标题对应的论文。已有数据，CPU。5 折交叉验证（按论文分折），ridge，bootstrap 置信区间。同上，CPU 作业 11438885
M3 换任务对照同一个标题，三种问法，都不含年份：“作者是谁”（Authors:）、“哪一年发表”（Year:）、“属于什么研究领域”（Field:）。存标题最后一个 token 和最后 “:” 的残差（L4–L63 共 15 层），并在输出处给真实年份和第一作者首 token 打分。分析：① 同一篇论文跨任务的相似度减不同论文的相似度（论文身份指数），按层画；② 在一种任务上训练的 probe（领域、年份、引用数、作者首 token）拿到另一种任务上测（跨任务迁移）；③ 任务本身能否从中间层读出。早期相同、后期分开 → 早期是“这篇论文”；早期就分开 → 早期是“任务”。新 GPU 前向：9,108 篇 × 3 种问法 = 27,324 次前向，每次只做前向（约 1–2 GPU 小时），残差约 8 GB。tiny 模型试跑 14/14 通过。已排队：接在 Stage 12 作业之后自动运行（Stage 12 没有可领单元时转交）
M4 作者专用 lensStage 12 正在用作者提示词拟合的 Jacobian lens（不是 WikiText）。如果它在中间层能读出名字而 WikiText lens 不能，说明信息在，只是换了基底。Stage 12 F1/F2，GPU拟合 35/40，进行中
M5 提议（尚未排）① 在标题之后的每个位置（右引号、年份、“Authors”、“:”）上训练 probe，直接看信息被搬到哪个位置、哪一层；② Patchscope：把中间层 “:” 的表示注入一个中性提示（如 “The first author is”）的同一层，让模型自己往下解码，看能否说出作者；③ 名字位置上（前面作者已给出时）的真/假标题判别。GPU，前向和少量替换等 M1–M3 结果再定
关于“区分真标题和假标题”本研究的假标题是同领域其他真实论文的标题，年份也匹配，而且在标题和 “:” 位置上下文里还没有任何作者名字。所以只看这两个位置的表示，“真标题”和“假标题”在设计上无法区分：两者都是真实论文。M2 改用“从标题推出年份、引用数、是否认得出”来检验模型是否认出了这篇论文。真/假判别要在上下文里已经出现作者名字的位置上做（M5③）。
