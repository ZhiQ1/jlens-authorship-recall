Stage 13B 读出工具C 哪一层 计划：中间层到底表示什么

计划写于 2026-10-28；状态随实验更新。

出发点

lens 读不出，只能说明“这种解码方式读不出”，不能说明信息不存在。logit lens 和三种 Jacobian lens 做的是同一件事：把某一层的表示直接翻译成“下一个词”，再看正确名字排第几。可是早期和中间层可能根本不在表示答案，而是在表示别的东西，比如“这是一个找作者的任务”“这篇论文是哪一篇”“接下来要输出人名格式”。这些信息可以真实存在，只是不在“名字”这个方向上，用名次去量自然量不出来。

现有数据支持这种看法：

  • Stage 11 替换显示，论文信息在 L24–L50 就从标题被读走，搬到标题后面那几个 token 上（L48 恢复 83%，L52 起 100%）；从 L52 起阻断对标题的注意力已没有影响。
  • 同一时期，在名字位置用 lens 几乎读不出作者（标题特异信号 L24–L48 约为 0）。
  • 换成在标题最后一个 token 上训练的线性 probe，从 L16–L24 起就能读出少量这篇论文特有的作者信息（+0.04 到 +0.08），而且对照检验证明它是这篇论文特有的。

信息在动，只是还没变成“名字”的形式。这一阶段要回答：中间层表示的是任务、论文身份，还是以另一种形式存在的作者信息？这是 Line B（读出工具）和 Line C（哪一层）之间的新方向。

三种假设及其预测

假设M1：lens 在中间层排第一的词M2：probe 读非名字的属性M3：换任务对照
H1 任务 / 格式：中间层在表示“要输出作者名单”多为 “author”、标点、名字常见开头，与标题无关论文属性读不出或很弱同一标题在不同问题下，中间层表示早早分开
H2 论文身份：中间层在表示“是哪一篇论文”与标题有关的词（照抄标题），换假标题就变领域、年份（从标题推出）、引用数、是否认得出都读得出，且早于名字不同问题下同一篇论文的表示在中间层相近，后期才按任务分开
H3 作者信息已在，只是不在词表方向不一定作者首 token 用 probe 读得出，lens 读不出按作者训练的 probe 能跨任务迁移；作者专用 lens（M4）在中间层读得出名字

三者不互斥。实验的目标是看每一层主要是哪一种，以及“论文身份”出现的层是否早于“名字”出现的层。

X2 只替换子空间（因果）用 M2/M3 的 probe 找出“论文身份”方向（领域、年份、引用）和“作者首 token”方向，只替换或抹掉这些方向，看作者能否被带过去或被破坏。只换身份方向就够：作者是之后从身份算出来的（H2）；必须换作者方向：作者信息早已以非词表形式存在（H3）。依赖 M3 的残差（不含年份的问法）；GPU 约 1 小时等 M3 结果后排队
X3 同义改写 vs 近邻标题先用 Qwen3-32B 把每个标题改写成意思相同、用词不同的版本（原始文本贪心生成，不用对话模板，避免 thinking）。自动检查：不含年份、不含作者姓、长度在原标题 0.5–2 倍之间；人工抽查通过后才开始正式运行。再比较原标题、改写标题、近邻标题 B（同领域、同长度）三者的各层表示和作者得分。某一层起改写标题比 B 更接近原标题，而且仍能说出作者：从这一层起表示的是“这篇论文”，而不只是主题词。Stage 11 样本；生成约 0.5 小时，正式运行约 1 小时生成已排队；正式运行等人工抽查（logs/para_ok）

实验判定规则（摘要）
M2c BERT 对照BERT 最好一层 ≥ Qwen 最好一层 − 0.05：年份和名气来自标题风格；Qwen 高出 ≥ 0.10（R²）或 ≥ 0.05（AUROC）：超出风格；其余：不能下结论
M3 换任务身份指数 I(l) = 同一论文跨任务余弦 − 不同论文跨任务余弦。H2（论文身份）：标题位置 I(l) > 0 从 L8–L24 起，跨任务迁移比 ≥ 0.8（L16–L40）。H1（任务）：L8–L24 的 I(l) 约为 0，或迁移比 < 0.5。L4 作为词汇下限
X1 跨任务替换恢复率 R = (替换 − 损坏)/(干净 − 损坏)。在调参集上选 R(作者) − R(随机 C) 最大的层；测试集上 R(年份)、R(领域) 都显著高于 R(随机 C)，且与 R(作者) 相差 ≤ 0.1：这一层的表示与任务无关。随机 C 的恢复预期约为 0，若某层超过 0.1，所有结果都相对它报告并标注
X3 同义改写差距 G(l) = cos(原, 改写) − cos(原, 近邻 B)。第一个 G 显著大于 L4 的层就是“论文身份”开始的层（调参集上找，测试集上确认）；行为上，改写标题的作者得分应高于 B
X4 Patchscope可解码度 D = 注入自身表示的得分 − 注入 B 的得分（年份、第一作者、领域）。H2 预测年份和领域最早可解码的层 ≤ 第一作者；认得出的论文 D 更大。源提示里没有年份，所以 D(年份) > 0 只能来自模型认出了论文

切分方式的审计与修正（2026-10-28 11:40，预注册补充 1，sha256 608045ca…9ad60f）M2、M2b、M2c 原来都用同一组按论文的 5 折（种子 13），同一篇论文的不同层、不同位置都在同一折。但有两处泄漏：
  • 假标题运行里，同一个借出标题被用在多篇论文上，有 2,004 个借出标题同时出现在训练和测试里。所以 false_0 的数字（读借出论文年份 R² 0.50–0.62）作废。
  • 没有按作者团队切：有 2,319 对论文共享至少一位作者全名，probe 可能只是记住了“这个团队常在哪年发论文”。
现在改为按组切：共享任一作者全名的论文为一组（同名不同人也并组，偏保守），false_0 按借出论文及其团队分组，整组进同一折。核对结果：没有任何作者全名或借出标题跨折，5 折大小均衡（1,821–1,822）。M2、M2b、M2c 按组重跑（作业 11443403）；X1/X3/X4 的调参集和测试集也改为按团队划分（0 个团队跨两边）。以按组切的结果为准，按论文切的结果并列保留，作为探索性结果。Stage 11 的 E4b probe 在再次引用前也会按组重跑。

已有结果（M1、M2、M2b 只有定性预测，作探索性结果看）

M1：lens 在中间层排第一的是什么词（名字的第一个 token，真标题）。

  • Jacobian lens：L24–L48 全部是 “.\n”“...\n\n” 这类“一句话或一段结束”的符号。L51–52 起出现名字，但都是 Robert、Zhang、David 这类常见名字，也就是名字先验。正确的那个 token 在 L52 只占 0.1%，L62 占 2%。
  • logit lens：L24–L56 几乎都是固定的垃圾 token（“工程技术”“您好”、垃圾词），这是 logit lens 在中间层的已知失效。L57 起才出现名字，L62 占 87%。
  • 真假标题对比：即使在 L24–L48，把真标题换成假标题，排第一的词也有 28–64% 会变。读出随标题而变，但变的不是名字。

这和 H1“表示格式”的预测一致，但更可能说明这些 lens 在中间层根本没在读内容，不说明信息不存在。

M2：在标题最后一个 token 上（年份还没出现）读论文属性。

  • 年份 R² 从 0.39（L16）升到 0.56（L52）。
  • 引用数 R² 从 0.28 升到 0.53；去掉年份后仍为 0.27 到 0.52，只用年份时是 0.05。
  • “是否认得出”AUROC 从 0.62 升到 0.67，只用年份时是 0.56。
  • 领域准确率 0.69–0.72，打乱标签对照是 0.13。
  • “:” 位置的年份 R² 达 0.98，这是泄题，只作阳性对照。
  • 假标题运行读出的是标题所属论文 B 的年份和引用数。 作废：同一借出标题跨了训练和测试，见上方切分审计。

M2b：标题词袋基线。只用标题词（TF-IDF）时，年份 R² 0.11，引用数 0.07，所以 Qwen 读出的不只是用词。但 L16 本身已经是很强的文本模型，词袋太弱，不足以下结论，所以加了 M2c（BERT）和 M3 的 L4/L8。另外，认得出的论文年份误差比认不出的小 0.7–1.2 年，可是词袋基线也小 0.88 年，所以目前还看不出“认得出”带来的额外信息。
