模型在哪一层“知道”一篇论文的作者

截至 2026-11-04，Stage 1–13 全部完成（答辩定稿，git tag defense-2026-11）。数字均可在实验记录 v26 和方法手册中追到出处文件。

研究问题。Qwen3-32B 常常在开放回答里写不出一篇论文的作者，却能在多选题里认出真作者名单。那么作者信息在网络的哪一层形成、经过哪些位置、能被哪种读出工具看到？

一句话结论：读得早，说得晚。论文信息从 L24 起在标题位置逐渐形成，在 L44–L52 进入名字位置（部分经由标题之后的 token）；但作者名字要到 L57–L61 才在名字位置被 lens 读出。“认得出”与“认不出”的论文只在最后几层拉开差距。中间层能读出论文的属性和标题的意思，但没有证明它表示的是“这一篇论文”本身。

怎么系统地做

研究分四条论证线，每条线先在小样本上建立信号、逐一排除替代解释，再在全部论文上复核和干预：

论证线要回答的问题小样本（Stage 1–9，20–200 篇）全量（Stage 10–13，9,108 篇）
A 这篇论文？信号是否针对这篇论文，而不是名字本身好猜5、7.2、7.3、810 标题特异信号；11 名字先验、probe 对照；13 X3
B 读出工具不同读出工具各能看到什么3、7.4、8、910 三种 Jacobian lens 与 logit lens；11 线性 probe；12 作者提示 lens；13 M2、X4
C 哪一层信号何时出现、何时被使用4、7.2、7.3、810 细层 L50–61；11 替换与阻断；12 P1/P2；13 X5–X7
D 哪个 token名字和提示的哪一部分带有信号6、7.110 名字格式与 token 角色；11 标题之后的 token

每一步用的控制

  • 对照组：“认得出”（target，4,621 篇）与“认不出”（control，2,220 篇）只在多选识别上不同；比较都在同一引用档内做。只用两组都没写对作者的论文（R0）复核，结论不变（输出处 +0.199 [0.187, 0.212]）。
  • 标题特异信号：真标题减去 5 个按领域和长度匹配的假标题的平均，另设“无标题”条件估计名字先验。
  • 因果干预：把真标题运行的表示替换进假标题运行（替换），或从某层起阻断对标题的注意力（阻断）；Stage 13 用另外 4 个假标题重做（X6、X7）。
  • 预注册：Stage 13 的判定规则在看数据前写定（prereg.json + 补充 1–5，均有 sha256）；所有层都报告，不挑层；调参集选、测试集确认。
  • 统计：区间以按作者团队整群重抽的 bootstrap 为主（同名作者的论文并为一组），probe 按团队分折，分折已存档并核对与原始运行一致。
  • 文本基线：用 BERT、TF-IDF、句子向量模型 all-mpnet 检查“只看标题文字能否得到同样结果”。
  • 工程自检：每个 GPU 作业前先在微型随机模型上跑通全流程，再跑一个真实分片；作业内做复现核对（如 X4 按 token 重算与原分数 4,712 个值逐位相同；P2 钩子的完全替换检查逐位恢复）。

主要发现

  1. 真标题有帮助，而且针对这篇论文。

    小样本：L56 真标题比错误标题高 +9.3 pp（Pilot50），在 200 篇新论文上 +5.18 pp [+2.93, +7.48]（Stage 8 冻结设计）。全量：标题特异信号在 L62 约 0.44；名字先验只占目标−对照差的约 1/3，在姓的第一个 token 上约为 0。

  2. “认得出”的优势是真的，但只在最后几层出现。

    引用档内的目标−对照差：中间层约为 0，输出处 +0.21。写对了部分作者的论文（R1）最强，但时间点相同。标题特异信号随引用数单调上升（ρ = 0.45）。

  3. 论文信息从 L24 起在标题位置逐渐形成，在 L44–L52 进入名字位置。

    替换标题之后的 token：L48 恢复 0.82，L52 恢复 0.995（5 个假标题平均，各假标题之间相差不超过 0.02）。从 L52 起阻断对标题的注意力，论文特有损失只剩 0.029（control 组 0.051，略高于 0.05 的预注册界线，到 L54–56 降为 0）。只替换名字位置在 L52 恢复 0.85，只替换 “:” 最多 0.17。注意力在 L48 把标题带进来（0.23），MLP 在 L52–56 接手（0.18、0.22）。

  4. 读出工具在中间层读不到“这篇论文的作者”。

    名字位置上，logit lens 和三种 Jacobian lens 在 L24–L48 的标题特异信号约为 0，Jacobian lens 多读出的只是“名字形状”；在作者提示上重新拟合的 lens（Stage 12 F2）也要到 L62 才区分目标组。标题位置的线性 probe 能读出少量论文特有信号（L24 +0.050、L40 +0.061、L56 +0.075，换成随机论文的作者后约为 0），但它只给名字第一个 token 打分，而这多半是首字母。

  5. 中间层在标题位置表示论文的属性，在 “:” 位置表示任务。

    标题最后一个 token 上，probe 读出发表年份 R² 从 0.38（L16）升到 0.56，引用数到 0.53，领域准确率约 0.70，“是否认得出”AUROC 0.62–0.67。换问法的对照（M3）显示标题位置的表示不随问法改变，但从不高于 L4（只有文字的层），所以不能说明超出文字；“:” 位置按问题重新组织。跨问法替换（X1）效果与问法无关。

  6. 改写标题：中间层表示了意思，但分不出是否“认出了论文”。

    改写后的标题在 L28–L40 比用词相近的另一篇论文更接近原标题（最高 L36 +0.16，超出 L4 文字水平），按预注册判据判为“存在论文身份信号”。事后加的检验把解读降级：只懂语义、不认识作者的句子向量模型在用词匹配的子集上也有相当的优势；中间层优势和行为恢复（约 90%）在 target 与 control 之间没有差别。两者都报告，并记为与预注册的出入。

  7. 从论文自己的标题状态，L8 就能解码出第一作者，但可能来自标题文字。

    X4 把标题状态注入中性提示：第一作者 L8 起可解码（+0.046 [0.035, 0.059]，主要在姓上），年份到 L40 才弱弱地出现，领域读不出，与“论文身份先于作者”的预测方向相反。在名的首 token 上，纯文本基线（BERT）不弱于 Qwen，所以不能排除文字解释。

  8. 名字内部：信号在姓上，首字母几乎不带信号。

    73% 的作者名以首字母开头，此时信号几乎都在后面的姓上（目标−对照 +0.253，首字母本身 +0.048）；完整的名本身也带信号。

复核中发现并改正的问题

  • E4b“只用假标题训练、信号反而更强”来自泄漏（同一借出标题同时在训练和测试里）；按团队分折并剔除标题复用后，信号与普通 probe 相当。标准化改为只在训练折内拟合，最大变化 0.0075，无结论翻转。
  • M3 的自动判定原来按绝对阈值写成“支持 H2”，不符合补充 2；按规则重判为不支持。
  • 团队分折在支持 AVX-512 的节点上会不同；核对后所有原始运行与存档一致（点估计差 0），现统一读存档。
  • X4 首次逐 token 自检对不上，原因是批大小不同造成的 bf16 舍入；按原批大小重算后逐位一致。
  • Stage 8 主终点在冻结前从 7 层积分改为 L56，git 中没有改动记录，决定依据待确认（见下）。

局限

  • 只用了一个模型（Qwen3-32B，bf16）。
  • 所有结论是教师强制打分下模型对正确作者的偏好，不是自由生成的过程。
  • “认得出 / 认不出”的标签来自组里的标注包，生成标签的代码（elm）不在集群上。
  • lens 的拟合稳定性只有 Stage 9 Fit A 一份证据；作者提示 lens 没做对半拟合。
  • X5 预注册的“跨问法检索”曲线没有计算；X2（只替换子空间）没有做。
