## Key findings

1. **Paper-specific author knowledge is readable only late.** spec is ≤ 0.05 at L24–L48 for every readout. It rises at L56 (+0.10 to +0.18) and is large at L62/L63 (target +0.48 to +0.58, control +0.20 to +0.25).
2. **target vs control, within citation bins:** about 0 at L24–L40. Slightly negative at L48 for the jlens lenses (−0.04 to −0.05). About 0 at L56 for jlens, +0.065 for logit. **+0.21 to +0.23 at L62/L63.**
   - Robust to dropping citation bins 0–4: +0.21 to +0.24 at L62/63.
3. The target advantage in the main report (+0.22 to +0.25 at L62/63) is almost entirely title-specific (spec +0.21 to +0.23). It is not explained by names that are easy to guess.
4. **Negative control:** spec on punctuation tokens stays near 0 (|spec| ≤ 0.014) at every layer, so the contrast does not create signal where there should be none.
5. Surname-first tokens carry most of the paper-specific signal: spec +0.80 to +0.88 at L62. Initials carry the least.
