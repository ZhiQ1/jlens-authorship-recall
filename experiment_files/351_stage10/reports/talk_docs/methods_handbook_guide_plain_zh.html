〇、先看这里：三处结论要降级

读手册时发现，有三处我们之前在 PPT 和讲稿里说得太满了。

1. M3 并不支持 H2（论文身份）

之前的说法：同一篇论文换问法，标题位置余弦 0.95–0.98，换问法移动距离只有换论文的 15–27%，所以标题位置存的是“论文身份”。

手册里的实际结果：预注册补充 2 规定，M3 只看“比 L4 高出多少”，因为 L4 几乎只是文字本身。结果：

  • 迁移比 T 在 L16–L40 约 0.92–0.99，但 L4 就已经是 0.98 / 0.98 / 1.00；T − T(L4) 在 L16–L40 是 −0.03 到 −0.06，区间不含 0。
  • 身份指数 I − I(L4) 在所有层都小于 0（L24 −0.011，L48 −0.052）。

意思是：中间层并没有比“只读了文字”的 L4 更“跨问法一致”。三种问法只在标题前 9 个 token 不同，标题完全一样，所以“换问法不变”几乎是构造决定的，不能证明有超出文字的论文身份。手册把这条标为“待复核”（附录 G4 的 V28）。

答辩怎么说：“M3 显示标题位置在换问法时基本不变，但这在 L4 就已经如此，按我们预注册的判据，它不能单独支持‘论文身份’。H2 目前主要靠 M2（标题位置能读出年份、引用数，且 Qwen 明显高于 BERT）和 X1（跨问法替换能恢复作者分数），而 M2 的 Qwen 胜过 BERT 按预注册只作参考。”

要改的材料：第 16 页三个假设表 M3 那列、H2 判断“Holds at the title position”，两份讲稿的 M3 段落。

2. X4 不能排除文字解释（H3）

之前的说法：纯文本基线读不出第一作者，所以 Qwen L8 的 +0.046 不是标题文字带来的。

实际结果：第一版文本基线（kNN）的阳性对照没通过，不作数；第二版在名字首 token 上文本基线不弱于 Qwen。另外 X4 还发现：第一作者 L8 就能解码，年份要到 L40，和 H2 预测的“先年份后作者”顺序相反。X4 中认得出的论文第一作者 D 更高（测试集不显著）这一差别不再作为 H2 的证据（只看标题文字的 BERT 基线 +0.088 不弱于 Qwen L8 +0.018）。

答辩怎么说：“X4 的作者信号出现很早，但我们不能排除它来自标题文字，所以单看 X4，H3 证据不足（2026-11-09 名字位置 probe 后 H3 总体改为部分支持）。”

3. X3 也不能证明“论文身份”

结果：改写标题在 L28–L40 比用词相近的近邻 D 更像原标题（最大 +0.16，L36），行为上保留原标题约 90% 的作者优势。但只懂语义的句子向量模型 all-mpnet 在用词匹配的子集上也有相当优势；而且 90% 在 target 和 control 之间一样。表示层面也一样：L36 上 target +0.158、control +0.160。

预注册上要说清楚：按补充 4 的字面判据，X3 其实判为“存在论文身份信号”。文本基线和 target/control 拆分是看到结果后加的，所以属于“与预注册的出入”，但方向是让结论更保守。

答辩怎么说：“X3 说明 Qwen 中间层表示了标题的意思，不只是用词。但不认识作者的语义模型也能做到，认不认得出也没有差别，所以它分不清认出论文和懂得意思。按预注册判据它是通过的，我们事后加的检验让解读更保守，两者都报告。M3、X3、X4 三个专门的区分实验，都没能证明是认出论文。”

二、工具是怎么做出来的

1. logit lens：最简单的读法

想法：模型最后一层是用 final norm + lm_head 把状态变成词。那把中间某层的状态也直接送进这一步，看看“如果在这里就停下来，模型会说什么”。

做法：lm_head(final_norm(h_l))，然后看正确名字 token 排第几。

缺点：中间层的状态和最后一层“说的是不同的语言”，直接套最后一步会读错。所以中间层几乎全是乱码 token。

2. Jacobian lens：先翻译再读

想法：既然中间层和最后一层“语言不同”，就先学一个翻译：第 l 层的变化会怎样影响 L63？用这个线性关系把中间层状态搬到 L63 的“语言”里，再变成词。

拟合一把 Jacobian lens 的步骤：

  1. 准备一批普通文本（比如 WikiText-103 的段落）。
  2. 每条文本跑一次前向，存下每层的状态。
  3. 对 L63 的 5,120 个维度，每次只在一个维度上放一个“1”，反向传播回第 l 层，得到“L63 第 d 维对第 l 层每个维度有多敏感”，也就是 Jacobian 矩阵 J_l 的第 d 行。5,120 维要反向 5,120 次（实际分批做）。
  4. 在这条文本的有效位置上取平均，跳过前 16 个位置（attention sink）和最后一个位置。
  5. 对所有文本的 J_l 不加权平均，就得到这一层的 lens。
  6. 使用时：lm_head(final_norm(J_l · h_l))。

我们用的四把：

  • public：Neuronpedia 公开的，557 条 WikiText-103，覆盖 L0–L62。具体用了哪 557 条已按它的代码复原，模型 revision 没有记录。
  • self100：Stage 3 自己拟合，100 条 WikiText-103，6 层。
  • fitA：Stage 9 的 Fit A，另外 100 条，7 层。
  • F1 作者 lens（M4）：Stage 12 用 40 篇“作者问法 + 真作者名单”拟合，专门针对作者任务。

为什么要四把：如果只有一把读不出，可能是这把不好；四把都读不出，才更说明信息不在“词的方向”上。

3. probe 的通用原理

想法：lens 是“现成的翻译”，读不出不代表没有信息。probe 是“专门为这个问题训练的翻译”：给它看几千篇论文的状态和答案，让它自己学怎么从状态读出答案，再拿没见过的论文测它。

为什么用线性、用 ridge：

  • 线性：只问“信息能不能用一个简单的加权求和读出来”。如果要很复杂的模型才读得出，那可能是 probe 自己算出来的，不是模型存的。
  • ridge：5,120 个权重、只有几千篇论文，很容易死记训练数据。ridge 在目标里加一项惩罚 α‖W‖²，让权重不要太大，减少死记。

每个 probe 都走的六步：

  1. 分 5 折（现在都按作者团队分）。
  2. 在训练折上标准化：每个维度减均值、除标准差，让 5,120 个维度在同一尺度。
  3. 选 α：在一组候选里，用第 0 折的留出误差挑最好的，之后 5 折都用它。
  4. 用闭式解算权重：W = (G + α·tr(G)/d·I)⁻¹ Aᵀ(Y − 均值)，G = AᵀA。
  5. 对测试折做留出预测。
  6. 跑对照：打乱标签、换答案、换输入。

4. E4b probe：是怎么想出来的

它要回答的问题：lens 在标题最后一个 token 上读不出作者，那这个位置的状态里到底有没有线性可读的作者信息？

难点：probe 需要“答案”来训练。年份、领域有现成标签，但“作者”是一串名字，没法直接当成一个数字去回归。

解决办法：不直接学“名字”，而是学“模型自己在 ‘:’ 处最后一层的状态”。原因是 “:” 处 L63 的状态，正是模型马上要说出第一个名字 token 时手上的东西，它经过 final norm + lm_head 就直接决定第一个名字。所以：

  • 输入 X：标题最后一个 token 在第 l 层的状态（5,120 维）。
  • 目标 Y：同一次运行里 “:” 处 L63 的状态（5,120 维）。
  • 学到的 probe 就是“从标题位置预测模型最终会在 ‘:’ 处想什么”。

之后怎么打分：

  1. 用 probe 对测试论文算出预测的 Y。
  2. 把它送进模型自己的 final norm，再只和 4,314 个名字 token 的 lm_head 行相乘（整个队列里所有作者的第一个 token 和所有姓的第一个 token）。
  3. 看每位作者第一个 token 在这 4,314 个里排第几，取 −log10，再对作者平均。
  4. 同一个 probe，输入换成 false_0 那遍（借来的标题）的状态，再打一次分。
  5. spec = 真标题分数 − false_0 分数。

参数：层 L16、24、32、40、44、48、52、56、60；α 候选 {0.1, 1, 10}，所有层都选中 1。

对照：

  • 换答案：用随机另一篇、同领域另一篇论文的作者去打分，约为 0，说明信号属于这篇论文。
  • 只用假标题运行训练：信号相近，说明 probe 学的不是“真标题提示”本身的特殊之处。
  • 复核：按作者团队分折、剔除一题两用的论文（剩 1,863 篇，E4b 信号只用其中 target + control 的 1,395 篇）、只在训练折内标准化（两种标准化差别最大 0.0007，结论不变）。

要主动说的局限：

  • 只打分第一个 token，而 73% 的作者第一个 token 是首字母，首字母几乎不带标题特异信号。所以它测的是信号最弱的那部分。补充 9（答辩后新增，分析计划在看结果前写定）把这个 probe 扩展到每位作者的全部名字 token 并按角色分开：L40 姓的第一个 token +0.071 [0.058, 0.085]（预注册版 V0：只减 false_0，目标 + 对照 1,395 篇，剔除标题复用，团队聚类 95% CI；381_stage13/reports/e4b_alltok.md），高于首字母 +0.044 [0.030, 0.057]（1,590 篇）；名的第一个 token 最强（L40 +0.124、L56 +0.163（1,706 篇））。原 E4b 只打分第一个 token（多半是首字母），所以低估了标题位置携带的名字信息。
  • 只减 false_0，没用 5 个假标题平均。
  • 目标是 “:” 处的状态（预测第一作者的首 token），却用来给所有作者的首 token 打分。

5. M2 probe：读论文的其他属性

想法：如果标题位置存的是“这是哪篇论文”，那年份、引用数、领域这些属性也应该读得出来。

做法：

  • 输入：标题最后一个 token 的状态，9 层。
  • 目标：领域（8 类，one-hot 编码，取最大的那类算准确率）、年份（R²）、log10(1+引用数)（R²）、去掉年份后的引用数（先用年份解释掉一部分）、认不认得出（target 记 1、control 记 0，用 ridge 回归再算 AUROC，在每个引用档内算再加权）。
  • α 候选 {0.01, 0.1, 1, 10, 100, 1000}。

对照：打乱标签；只用提示里的年份去预测（年份基线）；“:” 位置读年份当阳性对照（R² 0.97–0.98，因为年份就在提示里）；按论文和按团队两种切法比较。

结果（团队切）：年份 R² L16 0.38 → L52 0.56；引用数 0.29 → 0.53；领域准确率约 0.70–0.72；认得出 AUROC 0.62 → 0.67。年份基线只能把认得出做到 0.555。

6. M2b / M2c：文本基线

想法：年份、引用数也许光看标题用词就能猜，比如某个领域、某个年代的常用词。所以要一个“没背过这些论文”的模型做下限。

  • M2b TF-IDF：把标题变成词频向量（1–2 个词的组合），用 ridge 预测。结果年份 R² 0.10，引用数 0.08。但 TF-IDF 太弱，不能说明问题。
  • M2c BERT：用 bert-base-uncased 读标题，取每层平均向量，同样用 ridge。结果年份 0.24、引用数 0.19、认得出 0.63。按预注册，BERT 追平 Qwen 才算“风格解释”，Qwen 高出只作参考。

7. M3：同一标题换三种问法

做法：三种问法（问作者、问年份、问领域），标题前都对齐成 9 个 token，存 15 层在标题位置和 “:” 位置的状态。

两个指标：

  • 迁移比 T：在问法 a 上训练 probe，拿去预测问法 b，成绩 ÷ 在 b 上自己训练的成绩。接近 1 说明换问法不影响。
  • 身份指数 I：先把每种问法的向量减均值、变成单位长度；同一篇论文在两种问法下的余弦，减去和别的论文的平均余弦。越大说明“同一篇论文跨问法越像自己”。

为什么要和 L4 比：L4 几乎只编码了文字。如果中间层的 T、I 不比 L4 高，就说明一致性来自“标题文字一样”，而不是模型认出了论文。结果见第〇部分：不比 L4 高。

8. 替换（activation patching）

想法：probe 只能说明“信息在”，不能说明“模型在用”。替换是直接动手：把真标题那遍某处的状态塞进假标题那遍，看作者分数能恢复多少。

通用做法：两遍（真标题干净、假标题损坏），在第 l 层把指定位置的 block 输出替换，其余照常往后算。

恢复率 R = 平均(替换后 − 假) ÷ 平均(真 − 假)，先对所有论文平均再相除。

各个版本：

  • E1：替换整个对齐尾段（包括名字位置）。
  • E1t：只替换标题最后一个 token。
  • P1：一次只换一个位置（p1–p9 或全部名字位置）。
  • P2：只换某层注意力输出或 MLP 输出。
  • X1：把“问年份 / 问领域”时的标题状态换进“问作者”的那遍。
  • X6：E1 换成另外 4 个假标题重做。

9. 阻断（knockout）

做法：从第 l 层到 L63，禁止标题之后所有位置去注意标题 token，所有头都挡。实现方式是在注意力打分上加一个掩码，被挡的格子设成 bf16 能表示的最小值，softmax 后约等于 0。

损失 = 平均(真 − 阻断后) ÷ 平均(真 − 假)。

版本：E2 挡全部；E2n 只挡 “:” 和名字位置；X7 在假标题那遍也做同样阻断，扣掉“被挡本身造成的破坏”。

10. Patchscope（X4）

想法：把论文 A 的状态注入一个只写着占位符 X 的新提示，比如“Paper: X\nThe paper was published in the year”，看模型能不能据此说出 A 的年份。源提示里从来没有年份，所以说得出就只能是“认出了这篇论文”。

做法：源状态取标题最后一个 token 或 “:”，层 8、16、24、32、40、48、56；在目标提示里 X 那个位置的同一层替换；对照用搭档论文 B 的状态。D = 自己 − 搭档。最早可解码层在 tune 上找、在 test 上确认。

11. X4 文本基线

  • 第一版（kNN）：用 TF-IDF 或 BERT 找标题最像的 50 篇论文（排除 A 自己的团队），看 A 第一作者的姓是否出现在里面。阳性对照失败，结论作废。
  • 第二版（监督）：从标题文本直接训练分类器预测第一作者的名字首 token 和姓首 token。名字首 token 的阳性对照通过，姓的没通过。修正代码错误后，在名字首 token 上文本基线不弱于 Qwen。

12. X3：改写标题

想法：同一篇论文的标题换个说法，和一篇用词同样相近的别的论文比。模型如果认的是论文，改写版应该更像原版。

几个部件：

  • 改写由 Qwen3-32B 生成；和原标题完全相同的 27 条排除。
  • Jaccard：两个标题共有词数 ÷ 总词数，衡量用词重合度。原版分词丢掉了 3 个字母以下的词，导致 “M22” 这类被漏算，改成 jaccard2。
  • 近邻 D：同领域、无共同姓氏、和原标题 Jaccard 不低于改写版的另一篇论文。
  • NLI：判断两句话是否互相蕴含的模型，原→改、改→原都要成立。
  • Qwen 判断器：v1 一致率 7/19，v2 在新 20 条上 0.55，都低于 0.80，不用。改走备用方案：人工核对 + 剔除/不剔除两版敏感性分析。

13. 统计部分

  • 档内组差：只在两组都 ≥ 30 篇的 10 个档里比，按 n_t·n_c/(n_t+n_c) 加权。
  • bootstrap：Stage 10 起在“档 × 组”内重抽论文 2,000 次；Stage 13 起改为团队整群 bootstrap 为主。
  • 作者团队：共享任一作者全名就并组。注意：分组函数对同样大小的组排序不稳定，换一台机器分折可能不同，点估计最多差 0.006；M2 已把分折存成文件，其他脚本还没查。
  • 多重比较：Stage 10–13 没有做校正，规则是“所有层都报告、区间不含 0 才算”。Stage 8 补做了 Holm，只有 L62 通过。
