逐个实验讲解稿（方法详解版）：设计、数据处理、公式、结果、说明什么

配合 PPT v21 和报告第 30 版使用（2026-11-08 更新：P1 / P2 五个假标题、C / D 组补全、Stage 8 的三个前提和新增局限已加入；2026-11-06 更新：补充 9、X7 五个假标题等重做结果已加入）。第〇部分是所有实验共用的打分和统计方法，先讲一次，后面每个实验只讲自己特有的设计和公式。数字和定义均取自方法手册（2026-11-03 定稿）。

第〇部分：共用方法

0.1 模型与提示

  • 模型：Qwen3-32B，bf16，64 层，每层每个位置的内部状态（残差流）是 5,120 维。
  • 作者问法（裸文本，不套聊天模板）：

    Who are the authors of the paper titled "{标题}" ({年份})? Authors: {一位作者}

  • 单独打分（Stage 10 起的默认）：每位作者单独接在 “Authors:” 后面，各自一个上下文，和其他作者无关，即 encode(提示) + encode(" " + 作者名)。连写打分（“Authors: A1, A2, …”）只用在 Stage 11 的作者连写实验和 Stage 12 N1。
  • 关键位置：标题最后一个 token（这时模型还没看到年份，不会泄题）、“:”（它的输出就是第一个名字 token）、名字位置（回答里每个名字 token 所在的位置）。
  • 打分方式是 teacher forcing：把正确作者名直接放进回答里，看模型给它打多少分，而不是让模型自己生成。

0.2 一个 token 的分数

在某个读出工具 r、某一层 l、某个位置上，模型给出对全词表 V = 151,936 个 token 的打分 z。对正确 token g：

rank = 1 + #{v : z_v > z_g}（只数严格更高的；并列不往后排） nlr = log10(1 / rank) = −log10(rank)

排第 1 得 0，第 10 得 −1，第 100 得 −2，最低约 −5.18。不去掉特殊 token，比较对象是全部 151,936 行。

0.3 一篇论文的分数

mean_nlr(论文) = 这篇论文所有被打分作者的所有名字 token 的 nlr 平均

这是主指标，按 token 加权；按作者先平均再平均的版本作为次要指标一并报告。组间、层间比较时，先得到每篇的值，再对论文求平均。

0.4 七个提示条件与标题特异信号

同一篇论文、同一组名字 token，只换提示里的标题，共 7 个条件：真标题、5 个假标题（false_0…false_4）、删掉标题。

spec（标题特异信号）= true − (1/5) Σ false_k total = true − delete topic = false 平均 − delete

因为名字 token 完全相同，名字本身好不好猜在差值里抵消，spec 只剩“认得这篇论文”带来的部分。

算例（手册 G5.5，一篇真实论文，模型输出层，3 位作者 16 个 token）：

条件 mean_nlr
真标题 −0.7190
false_0 … false_4 −1.0234、−1.1540、−1.2625、−1.1334、−0.9895（平均 −1.1126）
删标题 −0.8808

spec = −0.7190 − (−1.1126) = +0.394，名次约好 2.5 倍 total = −0.7190 − (−0.8808) = +0.162 topic = −1.1126 − (−0.8808) = −0.232

这篇论文换上别的同领域标题，作者分数反而比不给标题还低（topic 为负），只有真标题才明显抬高。

0.5 假标题怎么选

对每篇论文，从同领域的其他论文里挑 5 个借标题，年份保留本篇自己的。先排除：本篇自己、和本篇有任何共同姓氏的论文、标题词重合（≥4 字母的词，Jaccard）> 0.6 的论文。然后按代价最小指派：

代价 = |Δ年份|/5 + |Δ作者数| / max(1, 0.25·n) + |Δ标题 token 数| / max(1, 0.2·长度) + 1.5·|Δ引用档|

按 strict → medium → loose → nearest 四档依次放宽，每档用匈牙利算法（linear_sum_assignment）做最小代价指派；strict、medium、loose 三档每个供体最多借出 5 次，nearest 档最多 7 次。false_0 是档最好、代价最低的那个。78.8% 的配对来自 strict 档。

0.6 target 与 control 的比较

只在两组都至少 30 篇的引用档里比（主分析 10 档：0–2 到 513–1024）：

target − control = Σ_b w_b · (target 平均_b − control 平均_b)，w_b = n_t·n_c / (n_t + n_c)，再归一化

两组越平衡的档权重越大。例：一档 target 100、control 30，权重 23；一档各 50，权重 25。

置信区间：Stage 10 在“档 × 组”内对论文有放回重抽 2,000 次取 2.5/97.5 分位；复核后改为按作者团队整群重抽，点估计不变。

作者团队：两篇论文共享任一作者全名就并成一组（并查集，A–B 共享、B–C 共享，则 A、B、C 同组），全队列 7,247 个团队。所有 probe 的 5 折都按团队分，同一团队全在训练或全在测试。

0.7 干预实验的两个比例

恢复率（替换实验）：

R(l) = 平均[ s(替换后) − s(假) ] ÷ 平均[ s(真) − s(假) ]

损失（阻断实验）：

Loss(l) = 平均[ s(真) − s(阻断后) ] ÷ 平均[ s(真) − s(假) ]

两者都是先对所有论文平均分子和分母，再相除，避免真假差接近 0 的论文把比值拉爆。例：真 1.0、假 0.2、替换后 0.6，R = 0.4/0.8 = 50%。

0.8 读出工具

  • logit lens：直接把第 l 层的状态送进最后一步：logits = lm_head(final_norm(h_l))。
  • Jacobian lens：先估计“第 l 层的变化会怎样影响 L63”：用一批普通文本，对 L63 的每个维度做一次反向传播，得到 Jacobian 矩阵 J_l，在有效位置（跳过前 16 个位置和最后一个）和所有文本上平均。使用时 logits = lm_head(final_norm(J_l · h_l))。三把 lens：public（Neuronpedia，557 条 WikiText-103）、self100（100 条）、fitA（另 100 条）。
  • 模型输出：L63 的真实输出。

0.9 名字 token 怎么切

注意有两种“切名字”，不要混：

（1）我们打分用的切分（方法手册 G5.2）：标注包的 authors 列按 “;” 切开、去首尾空白；每位作者前面加一个空格，用 Qwen 分词器切成 token。再给每个 token 标角色：按空白分词，最后一个词是姓；van、de、von 等是前缀；单个字母（可带点，如 “G.”）是首字母；其余是名；整个 token 都是标点（如 “.”）的记为 punct。每个词的第一个 token 记为“_first”，后续记为“_cont”。规模：33,811 位作者、149,999 个名字 token；没有作者因过长被排除。

（2）组长的 panel.py：把模型开放回答里写出的那一串文字切成一个个名字，用来算 M/H/U。这一项的规则还需要组长确认。

0.10 一致性检查（PPT 第 9 页）

  • 快路径（一次前向给整个名字打分）和慢路径（每个前缀单独前向）：最大 logit 差 0.16–0.37，约 1–1.5 个 bf16 单位；名次 1–41 完全一致。
  • 和 Stage 6 核对 972 个 token：token id 相同，log-prob 差中位数约 10⁻⁵。
  • 标点阴性对照：标点 token 的标题特异信号每层都约为 0。
  • 容差在看到 bf16 差距后从 0.25 放宽到 0.5，原记录保留。

第一部分：它知道吗？

实验 1：分组（Stage 1）

设计：用组长的标签流程，在同一个 Qwen3-32B 上对 9,108 篇论文做开放回答和多选题。

数据处理与公式：

  • 开放回答：chat 模板、关闭 thinking、贪心解码、最多 96 token。用 NameMatcher（姓 + 名首字母）把写出的名字和真名单匹配，得到 M（写对）、H（编造）、U（漏掉）。

    HR2 = (H + U) / (M + H + U) R0：M = 0；R1：M > 0 且 HR2 > 0.5；R2：HR2 ≤ 0.5（guard，不分析） 例：4 位作者，模型写了 3 个名字、1 个对 → M = 1, H = 2, U = 3，HR2 = 5/6 ≈ 0.83 → R1

  • 多选题：真名单 + 3 个同领域、同团队规模、同引用档、年份相近的真实团队，4 种顺序各问一次，读下一个 token 上 A/B/C/D 的概率。

    target：4 次全对且真选项平均概率 ≥ 0.5；control：最多对 1 次；其余 excluded

结果：target 4,621，control 2,220；其中“一个都写不对但多选全对”的 A 组 4,110 篇。不给标题时真名单被选为最像真的只有 25.5%（Stage 12 N1），等于瞎猜。

说明什么：“写不出但认得出”的论文大量存在；多选答对靠的是标题，不是名字听起来像。

实验 2：全队列逐层读出（Stage 10）

设计：9,108 篇 × 全部作者 × 7 个条件 × 4 种读出 × 6 层（L24、32、40、48、56、62）+ 模型输出，共 149,999 个名字 token。

数据处理：每篇按 0.3 算 mean_nlr，按 0.4 算 spec，再按 0.6 算档内 target − control。

样本范围：9,108 篇都跑了读出。“全部论文”的总体曲线用全部论文；组间比较只用 target（A + C）和 control（B + D），R2、识别不确定和 excluded 没有进入比较（由答辩后的分组对比补上）。

结果（读出工具都要说清楚）：

  • public Jacobian lens：L24–L48 两组 spec 都约为 0；L62 target +0.56、control +0.24（这是两组各自的平均，未按引用档配对）。
  • 模型输出层：两组平均约 0.48 和 0.20；档内配对的 target − control = +0.21 [0.20, 0.22]（按论文重抽的区间；改用团队整群后的区间待确认）。
  • 只用 R0（A vs B）：+0.20 [0.19, 0.21]（PPT 第 22 页；精确点估计 +0.199）。

说明什么：认得出的论文带有论文特有的作者信息，按 L62 的 +0.56 换算（10^0.56），真作者名次好约 3.6 倍；一个作者都写不对的论文也一样。但读出工具在中间层看不到。

实验 3：信号拆分（Stage 10）

公式：由 0.4 的定义，每篇论文都有恒等式

真标题分数 = 删标题分数（名字先验）+ topic（同领域标题带来的）+ spec（论文特有）

对三项分别做档内 target − control，三个差加起来正好等于真标题分数上的组差。

结果：target 和 control 在真标题分数上差 +0.247 = 先验 +0.087 + 主题 −0.047 + 论文特有 +0.207。

说明什么：主体是论文特有的，不是“这个领域常见这些姓”。

实验 4：独立复现（Stage 8）

设计：200 篇新论文，冻结分析计划后再看数据。

指标：

W = 正确作者第一个 token 的打分赢过 100 个错误作者第一个 token 的比例（金标准胜率） TA（标题优势）= W(真标题) − 20 个错误标题下 W 的平均 7 层积分 = L16、24、32、40、48、56、62 七层的平均

统计：W 中首 token 与错误作者并列时记 0.5。A − B 比较；冻结计划要求逐层 Holm 校正（按 p 值从小到大，第 k 个的门槛是 0.05/(m − k + 1)）和逐对剔除（LOPO：每次去掉一对论文重算），但原代码没有实现，两者都是 2026-10-30 事后补算（作业 11500770），p 值公式与检验族划分是我们的选择。

结果：冻结计划的主终点（7 层积分）A − B +2.41 pp，LOPO 100 次都不跨 0；Holm 校正后逐层只有 L62 显著。PROTOCOL.md 定的 L56 终点（同一 100 对）为 +4.98 pp [+0.32, +9.91]，LOPO 无变号但 14/100 次区间跨 0；积分终点约为 L56 的一半。

说明什么：主效应在新样本上复现，且不靠个别论文；逐层显著只在最后一层站得住，和“说得晚”一致。（主动说明：分析计划在 10-18 14:29 写定锁定（主终点为 7 层积分），同日 21:14 的 PROTOCOL 改为 L56，两者都早于 8C 打分；改动人和理由待查（U28）；两种都报告。）

2026-11-08（报告第 30 版）：Stage 8 的结论（真标题让模型更偏好真实第一作者 RQ1；A 组强于 B 组 RQ2）较稳，但有三个前提：① W 只给第一作者名字的第一个 token 打分，在 Stage 8 的 200 篇里有 129 篇（64.5%）这个 token 只是首字母（audit_20261105/part_A_stage4_9.md 第 10 行）；② 偏离 D13-1：按补充 13 C-2 的规则，全部作者 CPU 代理只在 L56 的 RQ2 上与已发表结论不一致（+0.064 [−0.032, +0.163]，区间含 0），触发了按原 W 在 GPU 上重算，用户 2026-11-06 决定不做；在锁定计划的 7 层积分终点上（近似，Stage 10 没有 L16）代理 RQ2 为 +0.046 [+0.007, +0.088]（L16 = 0）或 +0.049 [+0.005, +0.094]（L16 = L24），同向、区间不含 0（381_stage13/reports/c13_C2.md；381_stage13/c13_C2_followup/c2_followup_proxy.csv）；③ U28：L56 在锁定计划里是探索性次终点，10-18 21:14 的 PROTOCOL.md 把它改为主终点，改动者和依据仍未查清。

第二部分：什么时候知道？

实验 5：细层读出（Stage 10）

设计：在主轮 L40、48、56、62 之外，补算 L50–L55、L57–L61，只用 logit lens 和 public lens；L41–L47 和 L49 没有算。

结果：target − control 在 L50 为 +0.007，L62 为 +0.23；上升最陡在 L57–61。

说明什么：从读出工具看，“认得出”的优势只在最后十来层形成：“说得晚”。

实验 6：读出工具比较（Stage 10）

指标：除 nlr 外，看“正确 token 进前 10 的比例”；以及 lens 比 logit lens 多出的 spec。

结果：L48 Jacobian lens 前 10 命中 15–18%，logit lens 1%；L62 logit lens 最好（59%）。Jacobian lens 多出的 spec 只有 +0.01 到 +0.03，target 不比 control 多（L48–56 甚至为负）。

说明什么：更好的 lens 在中间层也看不到论文特有的作者信息，但“读不出 ≠ 不存在”，所以要动手干预。

实验 7：替换（Stage 11 E1）

设计：

  • 样本：每个引用档内 target、control 各取 min(60, n_t, n_c) 篇，种子 11，共 593 + 593 篇。
  • 两次前向：真标题（clean）和 false_0 假标题（corrupt）。
  • 在第 l 层，把 clean 那遍对齐尾段（右引号、年份、“Authors”、“:”和所有名字位置）的 block 输出复制到 corrupt 那遍对应位置，其余照常往后算。
  • 在模型输出上打分。

公式：0.7 的恢复率 R(l)。

结果：L24 约 0.07–0.09，L40 约 0.27–0.34，L48 约 0.82，L52 起约 1.0；target、control 时间点一样。只换标题最后一个 token（E1t）在 L40 前约 0.12–0.15，L56 后为 0。

说明什么：到 L52，论文信息已经全部到了标题之后的位置，比读出工具看到它早 5–10 层：“读得早”。

实验 8：阻断（Stage 11 E2）

设计：从第 l 层到 L63，在注意力打分上加掩码：标题之后的所有位置对标题 token 的那些格子设为 bf16 能表示的最小值，softmax 后约等于 0，所有头都挡。

公式：0.7 的 Loss(l)。

结果：从 L0 起挡损失约 0.83，L32 起约 0.37，L52 起约 0。只挡冒号和名字位置（E2n）最多损失 0.15，说明信息还能经由标题后其他 token 绕过去。

说明什么：L52 以后模型不再需要看标题，和替换从相反方向得到同一时间点。

实验 9：加固（X6、X7）

X6 设计：用 false_1…false_4 重做 E1。每个假标题长度不同，所以按同一公式为每个假标题重新计算对齐尾段，保证不把真标题 token 换进去；先用 false_0 重跑一个分片，必须和原结果逐个相同（516 行 × 15 层全部一致）。

X7 设计与公式：对 corrupt 那遍也做同样阻断，算它的损失 F；真标题那遍的损失 T。

论文特有损失 S = T − F（都以真假差为 1）

结果：X6：5 个假标题平均 L48 0.82、L52 0.995，每个和 false_0 最多差 0.02（预注册允许 0.10）。X7：L0 起挡 S ≈ 1.0；L52 起挡 target 0.018、control 0.051；L56 起都是 0。

2026-11-06：X7 补做了另外 4 个假标题，按 5 个平均判定，target、control 和全部论文都满足预注册判据（S(L52) 分别为 +0.022、+0.042、+0.028，均 ≤ 0.05）（补充 10 第 2 项；381_stage13/reports/b1_x7f_report.md）；原来对照组只用 false_0 时为 0.051，属于单个假标题的波动。

说明什么：时间点不依赖某个假标题；阻断结论不是“搞乱模型”造成的，挡住后真假标题的分数完全一样。

实验 10：哪个位置（Stage 12 P1）

设计：替换时只换一个位置。从提示末尾往前编号：p1 = “:”，p2 = “Authors”，p3 = “)?\n”，p4–p7 = 年份 4 位数字，p8 = “ (”，p9 = 右引号；另一个条件是“全部名字位置”。

额外处理：按 token 角色分开算恢复率：initial（单字母）、given（名）、surname（姓）；真假差 < 0.05 的角色（如标点）不报告比例。

结果：只换名字位置 L48 0.61、L52 0.85；只换 “:” 最多 0.172；其他单个位置 ≤ 0.03。姓的首 token 靠名字位置恢复（L52 0.92），首字母靠 “:” 恢复（L52 0.92，按 raw 重算的 0.917），但首字母真假差只有 0.11，姓约 0.5。

说明什么：信息主要直接进入名字位置，主要体现在姓上。

实验 11：哪个部件（Stage 12 P2）

设计：只替换第 l 层的注意力输出（o_proj 之后）或 MLP 输出（down_proj 之后），在加回残差流之前替换；替换范围是整段对齐尾部加全部名字位置（与 P1 的 all 相同），不只是名字位置。

结果：L48 注意力 0.23（MLP 0.07）；L52、L56 MLP 0.18、0.22（注意力 0.11、0.06）；L44 之前任何单个部件 ≤ 0.03。

说明什么：L48 注意力把标题信息搬进名字位置，L52–56 MLP 加工。单层替换是下限；MLP 是否“查记忆”分不出。

实验 12：标题位置的 probe（Stage 11 E4b）

设计：作者是一串名字，没法直接回归，所以学“模型自己在 ‘:’ 处 L63 的状态”，那个状态直接决定第一个名字 token。

数据处理与公式：

  1. 输入 X：真标题运行中标题最后一个 token 在第 l 层的状态（L16、24、…、60）；标准化（减均值、除标准差）。原版的均值、标准差用全部 9,108 篇（含测试折）计算；2026-10-30 改为只在训练折内计算后重算，E4b（target + control 1,395 篇）为 L40 0.061、L56 0.075；两种标准化差别最大 0.0007，0.066 / 0.080 是 X1 对照流程全部 1,863 篇的数字，差别来自论文集合，不是标准化，没有结论翻转。
  2. 目标 Y：同一次运行 “:” 处 L63 的状态。
  3. ridge 回归闭式解：

    W = (G + α·tr(G)/d · I)⁻¹ Aᵀ(Y − Ȳ)，G = AᵀA，α ∈ {0.1, 1, 10}，各层都选中 1

  4. 测试折上预测 Ŷ，经模型自己的 final norm，只和 4,314 个名字 token（队列里所有名字首 token 和姓首 token）的 lm_head 行相乘。
  5. 每位作者第一个名字 token 在 4,314 个里的 −log10(名次)，对作者平均。
  6. 同一个 W 输入 false_0 那遍的状态再打一次分；spec = 真 − false_0。
  7. 按团队 5 折；剔除“提示里的标题在训练中出现过”的论文，剩 1,863 篇（target 896、control 499）；E4b 信号只用其中 target + control 的 1,395 篇。

对照：把打分用的正确作者换成随机另一篇、或同领域另一篇论文的作者。

结果：全部作者、全部名字 token、按角色（补充 9，预注册版 V0，只减 false_0）L24 / L40 / L56：名的第一个 token +0.098 / +0.124 / +0.163，姓的第一个 token +0.058 / +0.071 / +0.098，首字母 +0.021 / +0.044 / +0.054。旧版只打首 token：L24 +0.050，L40 +0.061，L56 +0.075（E4b，target + control 1,395 篇；X1 对照流程全部 1,863 篇为 +0.050 / +0.066 / +0.080）；target 比 control 高 +0.03 到 +0.08（以上为旧版）。target − control（同一引用档内，全部作者全部名字 token 按角色，措辞 B 第 3 版）：预注册版中名的第一个 token 在 L24–L48 为正，姓在 L24–L48 不显著（L40 +0.012 [−0.026, +0.048]）；事后的逐个排除版中姓从 L24 起为正（L40 +0.030 [0.013, 0.048]）。名的信号在三版中一致；姓的证据弱，只来自事后版本。首字母在个别层为正、模式不一致（未做多层校正），不作结论。旧版的两个置换对照 −0.005 到 +0.006。两种标准化差别最大 0.0007（L24/L40/L56 ≤ 0.0004）。

说明什么：标题位置很早就有一点线性可读、属于这篇论文的作者信息，lens 读不到。信号小（名次好约 1.2 倍），而且只打分了第一个 token（73% 是首字母）、只减了 false_0，是辅助证据。

补充 9（答辩后新增，分析计划在看结果前写定）把这个 probe 扩展到每位作者的全部名字 token 并按角色分开：L40 姓的第一个 token +0.071 [0.058, 0.085]（预注册版 V0：只减 false_0，目标 + 对照 1,395 篇，剔除标题复用，团队聚类 95% CI；381_stage13/reports/e4b_alltok.md），高于首字母 +0.044 [0.030, 0.057]（1,590 篇）；名的第一个 token 最强（L40 +0.124、L56 +0.163（1,706 篇））。原 E4b 只打分第一个 token（多半是首字母），所以低估了标题位置携带的名字信息。

实验 13：层序汇总（X5）

设计：不做新计算，把各实验按自己的判定规则得到的“最早出现层”放在同一条层轴上。

结果：标题位置论文属性 ≤ L8–L16；替换 L48 恢复一半、L52 > 95%；阻断 L52 后无损失；名字位置 lens 读出作者 L53–L62。

说明什么：“读得早，说得晚”的完整时间线。

第三部分：中间层存的是什么？

三个假设：H1 任务/格式（“我要输出作者名单”）；H2 论文身份（“这是哪篇论文”）；H3 作者已经在了，只是不在词表方向上。所有判定规则在看数据前写进预注册（原文件 + 补充 1–5）。

实验 14：中间层排第一的词（M1）

设计：名字首 token 位置，看 Jacobian lens 和 logit lens 排第一的 token 是什么；再换假标题，看第一名变不变。

结果：L24–L48 Jacobian lens 第一名 100% 是 “.\n” 这类句末符号；L51–52 起出现 Robert、Zhang 等常见名；正确名字 L52 占 0.1%、L62 占 2%（logit lens 在 L62 的第一名有 87% 是像名字的 token，不一定是正确名字）；换假标题后 28–64% 的第一名会变。

说明什么：名字位置的中间层在 lens 看来是“格式”，支持 H1。

实验 15：读论文属性（M2、M2b、M2c）

设计：标题最后一个 token、9 层，按团队 5 折 ridge。

目标与指标：

  • 领域：8 类 one-hot，预测取最大一类 → 准确率
  • 年份 → R² = 1 − Σ(y − ŷ)² / Σ(y − ȳ)²
  • 引用数：log10(1 + 引用数) → R²；“去掉年份的引用数”先用年份解释掉一部分再预测
  • 认得出：target = 1、control = 0，ridge 输出当分数 → 每个引用档内的 AUROC，再按权重合并
  • α ∈ {0.01, 0.1, 1, 10, 100, 1000}

对照：打乱标签；只用提示年份预测（年份基线）；“:” 位置读年份作阳性对照；M2b 用 TF-IDF（1–2 词组）、M2c 用 bert-base-uncased 每层平均池化，同样 ridge。

结果：年份 R² 0.38 → 0.56，引用数 0.29 → 0.53，领域约 0.71（打乱 0.13），认得出 AUROC 0.62 → 0.67；“:” 位置年份 R² 0.97–0.98；BERT 0.24、0.19、0.63；TF-IDF 年份 0.10。

说明什么：标题位置早早就有论文属性，年份和引用数明显超过 BERT，部分支持 H2。但认得出这一项 BERT 也有 0.63，不作证据；按预注册，Qwen 胜过 BERT 只作参考。

实验 16：换问法（M3）

设计：同一标题三种问法（问作者、年份、领域），标题前的问法部分都对齐成 9 个 token，存 15 层在标题位置和 “:” 的状态。

两个指标：

迁移比 T = 在问法 a 上训练、到问法 b 上测的成绩 ÷ 在 b 上自己训练的成绩 身份指数 I = 同一篇论文两种问法下的余弦 − 和其他论文的平均余弦（向量先减均值、归一化）

判据（补充 2）：L4 几乎只编码文字，所以只看 T(l) − T(L4) 和 I(l) − I(L4)，区间不含 0 且大于 0 才算。

结果：标题位置年份 T − T(L4) 在 L16–L40 为 −0.03 到 −0.06，引用数也为负，领域和 L4 分不开；I − I(L4) 所有层 < 0。

说明什么：中间层不比 L4 更跨问法一致，“换问法不变”可能只是标题文字相同。M3 不支持 H2。

实验 17：跨问法替换（X1）

设计：把“问年份”（或问领域、随机另一篇论文 C）时第 l 层整个标题区间的状态，替换进“问作者”的那遍，在模型输出上给第一作者打分。1,178 对论文，按团队分调参 596 / 测试 582。

公式：

R(来源, l) = 平均[ s(来源替换) − s(corrupt) ] ÷ 平均[ s(clean) − s(corrupt) ] 判据：l ≥ 24 时，R(作者) − R(年份)、R(作者) − R(领域) 的区间都在 [−0.1, 0.1] 内，且 R(作者) − R(C) 下限 > 0 → 与任务无关

相似度检查：问法份额 = 同篇换问法的相对距离 ÷ 换论文的相对距离（0 = 问法不改变状态，1 = 和换论文一样远）。

结果：L24–L48 都判“与任务无关”；L48 作者 − 年份 +0.019 [0.012, 0.026]，很小但确实存在。标题位置问法份额 15–27%；“:” 位置 3–5 倍（L4–L40；L48 约 2.2 倍，L56–L63 为 1.3–1.5 倍）（x1_similarity.md colon 表）。

说明什么：“:” 存任务（H1）；标题位置跨问法通用，但同样受“标题文字相同”影响。

实验 18：改写标题（X3）

设计：每篇论文 A 有四个版本放进作者问法：原标题、Qwen 生成的改写、搭档 B、近邻 D。D 是同领域、无共同姓氏、词重合不低于改写版且最接近的另一篇论文；没有这样的论文时，取词重合最高的一篇（大多数论文走的是这条后备规则）。

数据处理：

  • 词重合 Jaccard2 = |W(t) ∩ W(p)| / |W(t) ∪ W(p)|，W 为去停用词、去后缀的词集。
  • 改写的质量：排除和原标题相同的 27 条；NLI 双向蕴含检查；人工核对 40 条；主分析 1,110 条，敏感性分析（剔除人工判为改意思和 NLI 未通过的）1,012 条。

公式：

G′(l) = cos(原, 改写) − cos(原, D)，在标题最后一个 token 判据（补充 4）：G′(l) > 0 且 G′(l) − G′(L4) > 0，调参集找到、测试集确认 行为：第一作者得分（改写） − 第一作者得分（D）> 0 词重合控制：回归里加 Jaccard 和共享稀有词比例

事后加的两项：

  • 文本模型基线：BERT、all-mpnet 算同样的 G′，减各自第 0 层。
  • target / control 拆开；行为恢复比例 = (改写 − D) ÷ (原 − D)。

结果：G′ 在 L4 就有 +0.30（来自用词），G′ − G′(L4) 在 L28–L40 为 +0.06 到 +0.16（L36 最大），行为 +0.24；按预注册判为“存在论文身份信号”。但在用词真正匹配的 66 篇中的 test 部分（37 篇）上，all-mpnet 的优势和 Qwen 相当（1.40 对 1.90，差的区间含 0）；target 和 control 完全一样（L36 +0.158 对 +0.160，行为恢复 0.90 对 0.91）。近邻 D 难配：改写词重合中位数 0.61，D 只有 0.15。

说明什么：Qwen 中间层表示了标题的“意思”，不只是用词；但分不清是认出论文还是懂得意思。解读降为“语义表示”，预注册结果和事后检验都报告。

实验 19：Patchscope（X4）

设计：把论文 A 在作者问法下第 l 层（8、16、…、56）标题最后一个 token 或 “:” 的状态，注入一个只有占位符 X 的目标提示（比如问年份、问第一作者、问领域），看模型说出的答案；对照用搭档 B 的状态。

公式：

D = s(用 A 自己的状态) − s(用搭档 B 的状态)，对 A 的正确答案打分 最早可解码层：调参集上 D 的区间第一次 > 0 的层，测试集确认

文本基线：只从标题文字训练分类器，预测第一作者名首 token 和姓首 token；阳性对照检查基线有没有能力测出东西。

结果：第一作者 L8 起可解码（+0.046）（全作者版本同样从 L8 起可解码：测试集 +0.048 [0.039, 0.058]），年份 L40 起（+0.013）。文本基线在名字首 token 上不弱于 Qwen（BERT +0.088 对 Qwen +0.018）；姓那一项的阳性对照没通过。

说明什么：作者信息出现很早，但不能排除来自标题文字，单看 X4，H3 证据不足（H3 总体判断见名字位置 probe：部分支持）；“先作者后年份”和 H2 预测相反。

第三部分小结

H1 在 “:” 和名字位置成立；H2 部分支持但未确立：M2、X1 有利，M3 不高于文字水平，X3 分不清语义和身份，X4 顺序相反；H3 部分支持（名字位置 probe，补充 11）。

收尾
