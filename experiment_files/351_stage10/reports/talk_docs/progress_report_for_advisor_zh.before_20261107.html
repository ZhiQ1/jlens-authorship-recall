项目进度汇报：Qwen3-32B 在哪一层“记住”论文作者

汇报人：Zhiqi Zhang　｜　截至 2026-11-03　｜　代码与结果 tag：defense-2026-11

一、一句话总结

对于模型写不出作者、但多选题认得出的论文，Qwen3-32B 内部确实带有这篇论文特有的作者信息：标题信息在 L44–52 被读进名字位置，到 L52 已全部到位，但要到 L57–61 才变成读出工具能看到的名字。我们称之为“读得早，说得晚”。中间层里存的是什么，我们检验了三个假设：任务/格式在冒号和名字位置成立；“论文身份”只得到部分支持，所有专门用来区分“认出论文”和“读懂标题意思”的实验都没能证明前者；“作者已经在那里”证据不足。

二、研究问题

模型经常编造论文作者。我们想知道：**它是真的不知道，还是知道但说不出来？**如果是后者，信息存在哪一层、哪个位置，又是在哪一步才变成说出口的名字。

核心思路是对比：同一份作者名单，配真标题和配假标题（借用同领域另一篇论文的标题）各跑一遍，两者之差只能来自“认得这篇论文”。再把论文分成“认得出”和“认不出”两组比较。

三、数据与分组

论文：9,108 篇，来自 Dreaming Up Authors 代码包（dua 1.0.0）的分层样本：从 OAG v2 抽取、经 5 道过滤剩 1,921,209 篇，再按 8 个领域 × 13 个引用档、每格最多 100 篇取样。标题、年份、作者、引用数来自 Semantic Scholar 2025 年 9 月快照。我们的 9,108 篇和包里逐篇一致。

标签：组长用 elm 流程在同一个 Qwen3-32B 上生成，我们原样使用。

  1. 开放回答：关闭 thinking、贪心解码、最多 96 token，用 NameMatcher（姓 + 名首字母）匹配，按写对比例分 R0（一个都没写对）、R1（写对少数）、R2（基本写对，作为 guard 不分析）。
  2. 多选题：真名单加 3 个同领域、同规模、同引用档的真实团队，换 4 种顺序问。4 次全对且真选项概率 ≥ 0.5 为 target，最多对 1 次为 control。
target（认得出） control（认不出）
R0 A = 4,110 B = 2,186
R1 C = 511 D = 34
合计 4,621 2,220

多选题是否只是“名字听起来更像”：不给标题时，真名单被选为最像真的比例是 25.5%，等于四选一瞎猜（Stage 12 N1），所以多选答对依赖标题。

假标题：每篇论文 5 个，同领域、保留本论文年份，按年份、作者人数、标题长度、引用档的加权差最小匹配，要求无共同姓氏、标题词重合 ≤ 0.6。

四、实验体系

1. 按研究问题划分 Stage

2. 四条论证线

  • **A 线：是这篇论文吗？**真标题 vs 假标题，论文特有信号是否存在。
  • **B 线：读出工具可不可靠？**多种 lens 交叉比较、probe、文本基线。
  • **C 线：发生在哪一层？**读出曲线、替换、阻断、层序汇总。
  • **D 线：落在哪个 token？**首字母、名、姓分开看。

3. 主要工具

工具 回答什么 做法
logit lens / Jacobian lens 某一层“想说”什么词 把中间层状态（经线性近似搬到最后一层）直接变成词表打分
probe 信息是否线性可读 5 折 ridge 回归，从内部状态预测答案，在没见过的论文上测
替换（patching） 信息何时、在哪里被用到 把真标题那遍某层某位置的状态塞进假标题那遍，看恢复多少
阻断（knockout） 之后还需不需要标题 从第 l 层起禁止标题之后的位置注意标题
Patchscope 状态里能解码出什么 把状态注入只有占位符的新提示，看模型说出什么
文本基线 是否只是标题用词 BERT、TF-IDF、句子向量模型读同样的标题

打分：正确名字 token 在全词表的名次，取 log10(1/名次)。两个分数差 d 等于名次好了 10^d 倍，比如 +0.21 是 1.6 倍，+0.44 是 2.75 倍。

五、主要发现

发现 1：认得出的论文，模型确实带有论文特有的作者信息（A 线）

  • 最后一层 L62，真标题比假标题对真作者的分数高约 0.44，相当于名次好 2.75 倍。
  • 分组看：target +0.56，control +0.24；target − control 在输出层为 +0.21 [0.20, 0.22]，几乎全部是论文特有的部分。
  • 只用 R0（一个作者都没写对的论文）重算，差值 +0.199，和全部 +0.207 几乎一样：写不出作者的论文里，模型照样“知道一些”。
  • 独立复现（Stage 8）：在 200 篇新论文上，按冻结计划的主终点（7 层积分），A − B 为 +2.41 pp，逐对剔除 100 次都不跨 0。逐层检验做 Holm 校正后，只有 L62 仍显著。
  • 拆分：真标题带来的 +0.247 = 名字先验 +0.087 + 领域主题 −0.047 + 论文特有 +0.207。
  • 引用数越高信号越强：Spearman ρ = 0.45。

发现 2：说得晚——名字到最后几层才读得出（C 线）

  • 中间层 L24–L48，两组的论文特有信号都约为 0。
  • 逐层细看：target − control 在 L50 只有 +0.007，L62 达 +0.23，上升最陡在 L57–61。
  • 所有读出工具一致：logit lens 在 L48 之前正确名字排在一万名以后，L62 跳到约第 10 名。Jacobian lens 在中间层多读出的部分只有 +0.01 到 +0.03，而且不偏向 target。

发现 3：读得早——信息在 L44–52 就已到位（C 线，因果证据）

  • 替换：把真标题那遍标题之后的状态塞进假标题那遍，L48 恢复约 0.82，L52 起约 1.0。
  • 阻断：从 L52 起挡住对标题的注意力，几乎没有损失。
  • 两项加固：
    • X6 用另外 4 个假标题重做替换，L48 平均 0.82、L52 平均 0.995，每个假标题和原来最多差 0.02。
    • X7 在假标题那遍也做阻断并扣除，“论文特有损失”从 L0 起挡是 1.0（全部消失），从 L52 起挡 target 约 2%、control 约 5%，到 L56 两组都为 0。所以阻断结论不是“把模型搞乱”造成的。
  • 层序汇总（X5）：标题位置的论文属性在最早测到的层（≤ L8–L16）就读得出；替换在 L48 恢复一半、L52 超过 95%；名字位置用 lens 读出作者要到 L53–L62。

发现 4：信息落在名字位置本身，先注意力后 MLP（D 线、Stage 12）

  • 逐位置替换（P1）：只换名字位置，L48 恢复 0.61，L52 恢复 0.85；只换冒号最多 0.17；其他单个位置都不超过 0.03。信息主要直接进入名字位置，不是先存在标题后面的 token 上。
  • 按 token 拆：首字母的信息经过冒号，但首字母本身真假差只有 0.11；姓的信息在名字位置本身，真假差约 0.5，是信号主体。
  • 按部件替换（P2）：L48 注意力恢复 0.23（同层 MLP 0.07）；L52、L56 的 MLP 恢复 0.18、0.22。顺序是注意力先把标题信息读进来，MLP 再加工。单层替换只是下限；MLP 那步是否是“查记忆”，这个实验分不出。

发现 5：标题位置有一点线性可读的作者信息（B 线）

  • probe 从标题最后一个 token 读作者，在按作者团队分折、剔除标题复用后（1,863 篇），从 L24 起 +0.05 到 +0.08，target 比 control 高 +0.03 到 +0.08。原版标准化用了全部论文，改为只在训练折内标准化重算后，L40 为 0.061、L56 为 0.075，结论不变。
  • 换成别的论文、同领域论文的作者打分，约为 0，说明信号属于这篇论文。
  • 局限：只给每位作者的第一个名字 token 打分（73% 是首字母），只减了一个假标题。补充 9（答辩后新增，分析计划在看结果前写定）把这个 probe 扩展到每位作者的全部名字 token 并按角色分开：L40 姓的第一个 token +0.071 [0.058, 0.085]（目标 + 对照 1,395 篇，剔除标题复用，团队聚类 95% CI；381_stage13/reports/e4b_alltok.md），高于首字母 +0.044 [0.030, 0.057]（1,590 篇）；名的第一个 token 最强（L40 +0.124、L56 +0.163（1,706 篇））。原 E4b 只打分第一个 token（多半是首字母），所以低估了标题位置携带的名字信息。减 5 个假标题平均的版本（2026-11-06 完成）：E4b 5 个假标题（偏离 D1 逐个假标题排除，保留 4,654 篇，平均 1.5 个假标题）：L40 姓首 token +0.076 [0.068, 0.083]，姓 − 首字母 +0.033 [0.023, 0.042]，原 E4b 第一个 token +0.066；置换对照首字母仍 +0.018，其余 ≈ 0；硬检查 E4b L40 +0.0609 PASS（补充 10 第 4 项；381_stage13/reports/b1_e4b5_report.md）。按逐个假标题排除、5 个假标题平均，姓的第一个 token 的 target − control 从 L24 起为正（L40 +0.030，L56 +0.058）；只用 false_0、样本较小时，L56 前不显著（同上，per-donor target − control 表）。

发现 6：中间层表示什么——三个假设的检验结果（Stage 13）

假设 判断 依据
H1 任务 / 格式 成立（冒号和名字位置） lens 在中间层名字位置 100% 把句末标点排第一；换问法时冒号位置的变化是换论文的 3–5 倍
H2 论文身份 部分支持，未确立 支持：标题位置能读出年份（R² 0.38→0.56）、引用数（0.29→0.53）、领域（准确率约 0.71，打乱标签 0.13），BERT 只读标题分别是 0.24、0.19；跨问法替换（X1）恢复作者分数差别在 ±0.1 内。不支持：M3 按预注册不高于 L4 的文字水平；X4 先解码出第一作者（L8）再解码年份（L40），和 H2 预测的顺序相反；X3 见下
H3 作者已在、只是不在词表方向 证据不足 专门用作者提示拟合的 lens 也读不出；probe 从 L8 起有作者信号，但只靠标题文字的基线不弱于 Qwen，不能排除文字解释

X3 是最关键的区分实验：同一篇论文改写标题，和一篇用词同样相近的别的论文比。

  • 结果：改写版在 L28–L40 比近邻更接近原标题（L36 最大 +0.16），行为上保留原标题约 90% 的作者优势。按预注册判据，这算“存在论文身份信号”。
  • 但我们事后加了两项检验：只懂语义、不认识任何作者的句子向量模型在用词匹配的子集上也有相当优势；而且 target 和 control 完全一样（行为 0.90 对 0.91，表示层 L36 为 +0.158 对 +0.160）。
  • 所以我们把解读降为“中间层表示了标题的意思而不只是用词”，分不清是认出论文还是懂得意思。预注册判据的结果和事后检验都如实报告。

六、如何保证实验的系统性与可信度

  1. 预注册：Stage 13 的每个判定规则都在看到数据之前写定，原始文件加 5 份补充，均有 sha256 并只读保存；文件修改时间和 git 时间证明写定早于数据。
  2. 严格的对照设计：每个主要结论都配阳性对照（如冒号位置读年份 R² 0.98，证明方法测得出）、阴性对照（标点 token、换成别人的作者）和打乱标签对照。
  3. 防泄漏：所有 probe 按作者团队分折（共享任一作者全名即同组，7,247 个团队）；剔除“同一个标题既当真标题又借给别人当假标题”的论文；标准化改为只在训练折内做（重算结论不变）；分折存档，所有脚本读同一份。
  4. 统计：target 和 control 只在同一引用档内比较并加权；置信区间改为按作者团队整群 bootstrap；Stage 8 补做 Holm 校正和逐对剔除。
  5. 多工具交叉验证：4 把读出工具、probe、替换、阻断、Patchscope、3 种文本基线，从不同方向回答同一问题。
  6. 复现检查：每次改代码重跑，都先用原设置复现旧数字（例如 X6 重算 false_0，516 行 × 15 层逐个相同）。
  7. 结论随证据调整：凡是新检验不支持的，就降级并写明，不删旧结果（见第七部分）。
  8. 完整记录：方法手册 290 页，每个数字追到脚本行号、结果文件、作业号和 commit；查不到的标“未知/需确认”。代码和结果打 tag defense-2026-11。

八、局限

  1. 只用了一个模型（Qwen3-32B），层数和机制是否适用于其他模型未知。
  2. 全部结论基于“把正确名字放进去打分”的教师强制偏好，不是模型自由生成时的行为。
  3. 读出工具的拟合稳定性只有 Stage 9 Fit A 一份证据；Fit B 与 holdout 已列入重做计划（补充 12，批次 2），尚未运行。
  4. bf16 一致性容差在看到差距后从 0.25 放宽到 0.5（原记录保留）。
  5. 高引用档几乎没有 control 论文，结论主要来自中低引用论文。
  6. 单层替换只给出下限；MLP 是否在“查记忆”无法区分。
  7. 标签流程的部分细节（干扰团队抽法、elm 版本等）还需组长确认。
