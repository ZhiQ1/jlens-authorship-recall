 <div class="half lt"><span class="tag ov">Overview · design</span><p class="m" style="font-size:19px">Stages 10–11 · 9,108 papers</p>
   <h2 style="font-size:46px;margin:2px 0 14px">Full-cohort design</h2><div class="t"><ul><li>All 9,108 papers, every author, every token</li><li>Score: rank over the whole vocabulary, log10(1/rank)</li><li>target = A + C, control = B + D (R0 + R1), compared within citation bins</li><li>5 matched false titles + no title</li><li>All layers reported, fine layers added</li><li>Parity and Stage 6 cross-check before analysis</li></ul></div><span class="pg"></span></div>
</div>
<div class="note" style="position:absolute;left:50%;bottom:58px;width:900px;margin-left:-450px;transform:rotate(-.5deg)"><span class="h">What changed in the design, and why</span>Small samples could not separate “small effect” from “no effect” in a given layer. The full cohort trades candidate-based scores for full-vocabulary ranks and pays for it with GPU time. <b>Note:</b> target/control include R1 papers; with R0 only (A vs B, as in the pilot) the output gap is +0.199 vs +0.207 and every layer looks the same.</div></section>

 <div class="col t">
  <table class="tb"><tr><th>Group</th><th>Recognition / open recall</th><th>Full</th><th>Pilot50</th></tr>
  <tr><td class="a">A</td><td>pass / R0 (no true author written)</td><td>4,110</td><td>20</td></tr>
  <tr><td class="b">B</td><td>fail / R0</td><td>2,186</td><td>20</td></tr>

  <ul style="margin-top:16px">
   <li>Pass = 4/4 option orders correct <i>and</i> mean true-option probability ≥ 0.5; fail = 0–1/4</li>
   <li>Pilot50: seed 35150, keeps the 20 Stage 4 papers + 30 new</li>
   <li>20 A/B pairs matched on exact field and citation bin, then |Δyear| + 2·|Δauthors|</li>
  </ul>
 </div>
 <div class="note" style="width:360px;margin-top:20px"><span class="h">Why A vs B?</span>
 Both groups write <b>no</b> correct author. They differ only in whether the model recognises the true list. That isolates “knows but cannot say”.<br><br>
 <span class="h">Caveat</span>In the 0–2-citation bin the strict pass rate is <b>25.5%</b>, above the planned ≤10% floor: “pass” is not proof of stored knowledge.</div>
