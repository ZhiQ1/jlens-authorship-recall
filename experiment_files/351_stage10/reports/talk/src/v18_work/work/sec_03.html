Stages 10–11 · 9,108 papers

Full-cohort design

  • All 9,108 papers, every author, every token
  • Score: rank over the whole vocabulary, log10(1/rank)
  • target = A + C, control = B + D (R0 + R1), compared within citation bins
  • 5 matched false titles + no title
  • All layers reported, fine layers added
  • Parity and Stage 6 cross-check before analysis
What changed in the design, and whySmall samples could not separate “small effect” from “no effect” in a given layer. The full cohort trades candidate-based scores for full-vocabulary ranks and pays for it with GPU time. Note: target/control include R1 papers; with R0 only (A vs B, as in the pilot) the output gap is +0.199 vs +0.207 and every layer looks the same.
