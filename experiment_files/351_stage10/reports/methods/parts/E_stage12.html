5 公式

对 token t，nlr = −log10 rank。对每个 (层 l, item i)，先在论文内对有效 token 取平均，再跨论文：

num_p = mean_t [ nlr_patch(t, l, i) − nlr_none(t, l) ]
den_p = mean_t [ nlr_true(t)       − nlr_none(t, l) ]
recovery(l, i) = mean_p(num_p) / mean_p(den_p)       （比值的均值，不是均值的比值逐篇）
95% CI：论文重抽 2000 次，对每次重抽重算比值，取 2.5/97.5 百分位

注意 none 按层取（同一层所在的 batch 块里的未替换拷贝），分母也随层变。stage12_analyze.py:12-14 boot_ratio()、46-59

P2 注意力 vs MLP 组件替换（patch_comp）

1 问题与作用

Stage 11 E1 说明论文信息在 L24–L50 间到达标题之后的位置。P2 问：是注意力把标题信息"搬"过来，还是这些位置上的 MLP 自己"算"出来？做法：只把某一层的注意力输出或 MLP 输出换成 true 运行的，其余照常。371_stage12.py:9-11

2 材料

与 P1 相同：Stage 11 样本 1,186 篇、4,307 个上下文、19,077 个名字 token；true vs false_0。层 PC_LAYERS = [8, 16, 24, 28, 32, 36, 40, 44, 48, 52, 56]；组件列表 comps = ['none'] + 每层的 attnl、mlpl，共 23 项。371_stage12.py:37, 146 · raw/patch_comp/*.npz comps

3 工具

PyTorch forward hook 挂在 子模块 上：

  • 注意力：model.layers[l].self_attn（HF Qwen3Attention）。其 forward 返回 (attn_output, attn_weights)，其中 attn_output = self.o_proj(...)，即 o_proj 之后、加回残差之前的注意力输出。hook 取/改 o[0]。
  • MLP：model.layers[l].mlp（Qwen3MLP），输出 = down_proj(act(gate_proj(x)) * up_proj(x))，即 down_proj 输出、加回残差之前。
  • Decoder block 里：h = residual + self_attn(input_layernorm(residual))[0]，然后 h = h + mlp(post_attention_layernorm(h))。所以替换后的组件输出在本层被加回 false 运行自己的残差流（注意力输出加在 block 输入残差上；MLP 输出加在注意力之后的残差上），下游所有层照常重算。

371_stage12.py:156-157（记录）、166-171（替换）· transformers 5.19.0 models/qwen3/modeling_qwen3.py:271-272（o_proj）、81（down_proj）、296-314（decoder layer 残差相加）。注：运行时的 transformers 版本未写入 meta，此处是当前 conda 环境的版本

4 步骤

  1. 每个作者上下文 T、F、posT/posF 同 P1；tail = S + len(name) − 1（对齐提示尾部 + 全部名字输入位置，即"标题之后的全部 tail"，与 P1 的 all 相同）。371_stage12.py:150-151
  2. 跑 T 一次，在 PC_LAYERS 每层的 self_attn 和 mlp 上挂记录 hook，存 o[0][0, -tail:]（注意力）和 o[0, -tail:]（MLP）——即最后 tail 个位置的组件输出；同时得到 rank_true。371_stage12.py:154-160
  3. 把 F 复制 23 份放进一个 batch；第 e 份（comps[e] = attnl 或 mlpl）在第 l 层对应子模块的输出上执行 t[e, -tail:] = 记录值（只改这一份、这一层、这个组件、最后 tail 个位置）；第 0 份 'none' 不改。371_stage12.py:161-174
  4. 在最终输出（block 63 + final norm + lm_head）对每个名字 token 求 rank。361_stage11.py:219-222

5 公式
