## 1. C24 输出置信度基线收尾
**1a 只读核查（CPU）**：第 0 片（143 篇、4,566 个位置）中重放 argmax 与生成 token 不一致的约 2.1%（97 个位置）：
- 两者的 logit 差 / 对数概率差，是否都 ≤ 几个 bf16 单位（|logit| 32–64 时 1 个单位 = 0.25；判据：差 ≤ 4 个单位记"几乎并列"）；
- 是否集中在名字 token（名字 token / 其他位置的比例 vs 全部位置的基础比例）；
- 在这些位置用重放概率代替生成概率，每个名字的置信度分数（名字全部 token 平均 log-prob、熵、最小 log-prob）变化多大（中位数、最大值，影响到的名字比例）。
- 决策：若不一致位置 ≥ 95% 几乎并列且名字置信度变化可忽略（中位 |Δ| < 0.01）→ 记 WARN、用重放概率续跑全部 48 片（CPU / GPU 视存储而定）；否则估算"重新生成并保存 logits"的成本，先发用户。
**1b 名字特征基线修正（CPU）**：名字出现频率改为排除当前论文（与知名度同规则），重算名字特征基线与合并基线。
**1c 主比较**：probe 相对"输出置信度 + 排位 + 名字特征（修正后）+ 知名度"合并基线的论文内 AUROC 增量（同一组团队 bootstrap 上的配对差），L16–L56 七层；同时报 probe 相对单个置信度基线的增量。
**判据**：增量 CI 不含 0 且 > 0 → C24 改写为"在控制输出置信度后仍有增量"；否则降级为"probe 信号可由输出置信度解释"（按此前用户规则）。若"名字写出之前"的位置也能分开 → 先问用户。
**算力**：1a、1b CPU；续跑 48 片若需 GPU 重放，估约 0.5 A100 小时（已批准）。

## 2. H3 同尺度比较（名字位置，probe vs lens）
**问题**：之前 probe 在 9,137 个名字 token 内排名、lens 在全词表排名，尺度不同不能比大小。
**设计**：同一批 4,654 篇（Vpd，姓首 token）、名字位置、L40 / L48；把 public J-lens 和 logit lens 的输出也限制在同样 9,137 个名字 token 内求名次 → nlr；算 spec（真标题 − 假标题，与 probe 同一套假标题规则）和 target − control。
**主比较**：probe(T − C) − lens(T − C)，同一组团队抽样，L40、L48 各一，J-lens 为主、logit 为辅。
**判据**：差的 CI 不含 0 且 > 0 → "在同一尺度上 probe 读出的论文特有作者信息多于 lens"（H3 证据加强）；含 0 → 维持"部分支持"。
**算力**：若已存名字位置的 lens logits（或可由残差 × lens 矩阵在 CPU 上重算）→ CPU；否则需要 GPU 重放名字位置残差，估约 1–2 A100 小时（先查存储）。

## 3. 标题位置 probe 的干净样本（CPU）
**问题**：V0 只排除 false_0 的泄漏，Vpd 逐个假标题排除；仍可能有供体论文在训练集里。
**设计**：5 折作者团队交叉验证；测试每一折时，从训练集中去掉该折全部论文的全部供体论文（5 个假标题的供体都算），使测试论文的 5 个假标题都"干净"；其余与补充 9 相同（全部名字 token、训练折标准化、α 在第 0 折选）。
**报告**：每折保留的训练篇数、每篇测试论文可用的假标题数分布；姓首 token、名首 token、全部 token 在 L40 的 spec 与 target − control（团队 CI）；与 V0、Vpd 并列。
**判据（描述为主）**：姓首 token L40 target − control 的 CI 是否不含 0。
**算力**：CPU（已存残差）。

## 4. H2 虚构论文
**问题**：标题位置的"论文身份"信号，是来自"这篇真实存在的论文"，还是任何看起来合理的同领域标题都会有？
**设计**：为每篇样本论文生成 1 个同领域、意思相近、但不存在的虚构标题。
- 生成方法：用 Qwen3-32B（thinking 关闭，温度 0.7）给定真标题与领域，提示"写一个同领域、主题相近、但不同的、看起来真实的论文标题"；过滤：与数据集全部标题及真标题的词重叠（jaccard2）< 0.3，长度在真标题 ±30% token 内；并用检索（数据集 9,108 篇 + 标题精确 / 近似匹配）确认不存在。
- 人工抽查规则：随机抽 100 个（固定种子），两条标准：同领域、看起来像真论文；不能是已知论文的改写。不合格率 > 10% 时修改提示并重抽，记录次数。
- 样本：Stage 11 样本 1,186 篇（593 + 593）。
**测量**：真 vs 虚构标题在：标题位置作者 spec（全部 token）、M2 读出（年份、引用、领域的 probe 读出）、E1 恢复比例（把真 / 虚构标题运行的状态替换进假标题运行）。
**主比较**：真 − 虚构 的差，target / control 分开，团队 CI。
**判据**：作者 spec 与 E1 恢复上真 − 虚构 CI 不含 0 且 > 0，而 M2 读出差约为 0 → "身份信号来自真实论文，不只是合理的标题"（支持 H2）；若真 ≈ 虚构 → 不支持。
**算力**：生成标题 + 三项前向，估约 3–5 A100 小时（实测后先问）。需先锁定补充 17（预注册）。
